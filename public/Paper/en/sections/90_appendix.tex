\section{Build and Reproduction Commands}\label{app:build}

The Chinese version uses XeLaTeX with ctex (\texttt{fontset=windows}); the English version uses pdfLaTeX. Both compile in the order: first pass $\to$ BibTeX $\to$ two passes. The values in Figures~\ref{fig:tiling}, \ref{fig:vram}, and~\ref{fig:pipeline} come from the macros in \texttt{data/results.tex}; text and figures share one macro source, so injecting real results only requires editing that file.

Dependencies: Python $\ge$ 3.10, torch 2.5.1, numpy 1.26.4, opencv-python 4.8+, scikit-image 0.25.2, monai 1.5.2, scipy 1.15.3. Data preparation, training, and evaluation commands are in the engineering Runbook and are not duplicated here, to avoid version drift.
